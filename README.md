# Comunicação Cliente-Servidor em Python

Projeto acadêmico desenvolvido em Python com o objetivo de demonstrar a comunicação entre um **cliente** e um **servidor** utilizando **sockets**.

O projeto apresenta, de forma prática, o funcionamento de uma comunicação entre aplicações utilizando o modelo Cliente-Servidor.

## 📌 Sobre o projeto

Neste projeto foi desenvolvida uma aplicação composta por dois programas:

- **Servidor:** responsável por aguardar conexões e estabelecer a comunicação.
- **Cliente:** responsável por se conectar ao servidor e realizar a comunicação.

A atividade também contém imagens que registram as etapas do desenvolvimento e da execução do projeto.

## 🎯 Objetivos

- Compreender o funcionamento do modelo Cliente-Servidor.
- Utilizar sockets para estabelecer uma comunicação entre aplicações.
- Desenvolver uma aplicação simples de comunicação utilizando Python.
- Compreender o processo de conexão entre cliente e servidor.
- Registrar as etapas de desenvolvimento e execução do projeto.

## 🛠️ Tecnologias utilizadas

- **Python**
- **Sockets**
- **TCP/IP**
- **GitHub**
